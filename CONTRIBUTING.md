# Руководство для участников

Спасибо, что решили помочь проекту! 🚀

## Как внести вклад

1. **Нашли ошибку?** – откройте Issue, подробно описав проблему (версия Windows, поведение скрипта).
2. **Хотите добавить фичу?** – обсудите её в Issue перед реализацией.
3. **Готовый Pull Request** – следуйте стандартному flow GitHub:
   - Форкните репозиторий
   - Создайте ветку с описательным именем (`fix-dns-error` или `feat-multiple-adapters`)
   - Внесите изменения и проверьте работу на Windows 11 (или другой версии, если ваш шаблон под иную ОС)
   - Опишите изменения в PR

## Требования к коду

- Скрипты должны запускаться на Windows 11 (с поддержкой русского языка)
- При создании скрипта для другой версии, следует это явно указать в названии шаблона
- Основная кодировка – `chcp 1251`
- Все новые параметры должны быть настраиваемыми в начале файла
- Скрипт не должен требовать установки сторонних программ

## Тестирование

Перед отправкой PR протестируйте скрипт как минимум в двух сценариях:
- С включённым прокси
- С выключенным прокси
- С недоступной сетью (проверка fallback-сообщений)

Спасибо!
