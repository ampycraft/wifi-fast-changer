# wifi-fast-changer

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform: Windows](https://img.shields.io/badge/Platform-Windows%2011-blue.svg)]()

Утилита для **мгновенного переключения сетевых профилей** на ноутбуках с Windows 11.  
Одним щелчком меняет точку доступа Wi-Fi, DNS-серверы и системный прокси (включая WinHTTP).

> **Проблема:** Частое подключение к разным Wi-Fi сетям (офис, дом, коворкинг) требует ручной смены прокси, DNS и других параметров.  
> **Решение:** Набор BAT-скриптов, каждый из которых активирует заранее заданный профиль со всеми настройками.

## Возможности

- 🔄 **Автоматическое переключение Wi-Fi** (без прямой команды `netsh wlan connect`, чтобы избежать ошибок геолокации)
- 📡 **Установка статических DNS** (основной + дополнительный) на беспроводном адаптере
- 🌐 **Включение/отключение системного прокси** (Internet Settings) и прокси WinHTTP
- 🎛 **Управление автоподключением:** указанная сеть становится единственной с галкой «Подключаться автоматически»
- 🛡 **Проверка прав администратора** и стабильное ожидание подключения
- 💬 **Подробные сообщения** о каждом этапе выполнения

## Требования

- **Windows 11** (должна работать и на Windows 10, но тестировалось на 11)
- Запуск **от имени Администратора** (обязательно для смены DNS и перезапуска адаптера)
- В системе должен быть сохранён хотя бы один профиль нужной Wi-Fi сети (подключитесь к ней вручную один раз)

## Быстрый старт

1. Скачайте репозиторий или создайте новый `.bat` файл на основе приложенного шаблона.
2. Отредактируйте блок настроек в начале скрипта под свою точку доступа.
3. Запустите скрипт **от имени Администратора** (правый клик → `Запуск от имени администратора`).

Для каждого нового подключения создайте очередной `.bat` файл

Пример настроек для домашней сети:

```bat
set "WIFI_SSID=MyHomeWiFi"
set "DNS1=8.8.8.8"
set "DNS2=8.8.4.4"
set "PROXY_SERVER="
set "PROXY_BYPASS="
set "PROXY_ENABLE=0"
```

После запуска скрипт:
- Отключит автоподключение для всех сетей, кроме MyHomeWiFi
- Перезапустит Wi-Fi адаптер, чтобы система сама подключилась к нужной сети
- Назначит DNS 1.1.1.1 и 1.0.0.1
- Отключит прокси

## Часто задаваемые вопросы
### Почему не используется netsh wlan connect?
На Windows 11 эта команда требует включённой геолокации. Вместо неё скрипт временно отключает и снова включает Wi-Fi адаптер. Благодаря предварительно настроенному автоподключению система сама цепляется к нужной сети.

### Как узнать точное имя адаптера?
Если автоопределение не сработало, откройте командную строку и выполните:
```bash
netsh interface show interface
```

Найдите строку с типом `Беспроводная` или `Wi-Fi` и замените значение переменной `WIFI_ADAPTER` в скрипте на точное имя из вывода.

### Можно ли использовать скрипты на Windows 10?
Да, принципиальных отличий нет. Однако Windows 10 может нормально отрабатывать netsh wlan connect. При желании вы можете заменить блок «Перезапуск адаптера» на более быстрый метод с прямым подключением.

### Что делать, если после переключения не работает интернет?
Убедитесь, что профиль сети сохранён (подключитесь к ней вручную хотя бы раз).

### Проверьте правильность DNS-адресов.

Запустите скрипт от имени администратора.
